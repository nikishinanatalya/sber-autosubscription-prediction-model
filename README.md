# Сервис предсказания совершения целевого действия пользователем на сайте «СберАвтоподписки».

### Требования:

1. Создать модель предсказания совершения целевого действия, ориентировочное значение ROC-AUC ~ 0.65.
2. Упаковать получившуюся модель в сервис, который будет брать на вход все атрибуты, типа utm_*, device_*, geo_*, и отдавать на выход 0/1 (1 — если пользователь совершит любое целевое действие).

### Исходные данные:

- GA Sessions датасет - информация о клиенте, устройстве, характеристиках привлечения клиента на данный сайт; 
- GA Hits датасет - информация о совершенных клиентом действиях на сайте.
- справочники целевых действий, видов рекламы в социальных сетях и органического трафика.

### Реализация проекта:

#### Предобработка датасета:

1. Создание единого датасета с целевым признаком.
Характеристики датасета:
- 1,7 млн. записей;
- все признаки категориальные;
- 3% целевых действий - выраженный дисбаланс классов.

2. Заполнение пустых значений путем формирования словарей из существующих данных, базирующихся на следующих гипотезах:
- клиент заходил на сайт с одного устройства, при условии, что часть характеристик этого устройства известны;
- существуют операционные системы и браузеры, которые могут быть установлены на устройствах определенных брендов;
- клиент заходил на сайт с одного и того же канала привлечения, воспользовался конкретным предложением маркетинговой кампанией или типом привлечения в определенный интервал времени и в определенной локации;
- существуют уникальные комбинации среди признаков отвечающих за привлечения клиента.

Пустые значения объектов, для которых гипотезы не сработали, были заполнены значением _none_. Признак с 99% пропущенных значений удален.

3. Создание новых признаков для анализа данных и построения модели:
- временные: месяц, день недели, день;
- неинформативные объекты, аномальные объекты, категория приложения, органический трафик, социальные сети.

4. Объединение значений основных признаков в группы по количеству совершенных целевых действий для предотвращения огромного увеличения датасета после кодирования (One-Hot Encoding).

#### Анализ полученных данных:

1. Построение гистограмм для выявления клиентской активности.
2. Построение тепловых карт для визуализации самых популярных каналов привлечения, типов привлечения, брендов устройств и их комбинаций в разных временных разрезах.

#### Выбор и тюнинг модели:

Был выбран алгоритм Логистической регрессии, который показал стабильный результат на кросс-валидации.
Полученное значение метрики ROC-AUC ~ 0.69.
Анализ и обработка данных отражены в ноутбуке Final work.ipynb.

#### Создание сервиса:

1. Вынесение операций предобработки данных в отдельные функции: merge_datasets.py, update_dataset_v2.py, transform_dataset_v2.py.
Реализация словарей обработки тренировочных данных с целью их применения на новых объектах.
2. Формирование пайплайна, выполняющего предобработку, обучение и сохранением модели с метаданными в сериализованный pkl файл: pipeline_v2.py.
3. Создание сервиса для передачи входящих данных в модель и получения ответа посредством FastAPI и Uvicorn: main_v2.py.
4. Проверка работы модели через Postman: скриншоты - predict_1, predict_2, predict_3.

### Результаты:

1. Веб-сервис передает входящие данные в модель, выполняющей их предобработку и прогноз, возвращает результат прогноза в виде предсказания классов: 0 или 1.
2. Несмотря на дисбаланс классов, модель предсказывает совершение целевого действия на входящих данных: как 0, так и 1.
3. Качество полученной модели превысило требуемое: ROC-AUC ~ 0.69.
